# Give Love — журналы в подарок

Сайт-витрина шаблонов персональных журналов. Чистый HTML, CSS и JS, сборка не нужна.

## Структура

```
givelove/                      ← корень репозитория
├── index.html                 ← главная страница (разметка, превью ссылки, иконки)
├── .nojekyll                  ← говорит GitHub Pages отдавать файлы как есть
├── README.md
├── css/
│   └── style.css              ← все стили (цвета, шрифты, раскладка)
├── js/
│   ├── data.js                ← каталог: шаблоны, цены, категории, наборы
│   └── main.js                ← логика: каталог, карточка, листалка, корзина
└── images/
    ├── logo.jpg               ← логотип в шапке и подвале
    ├── og-image.jpg           ← картинка превью ссылки (1200×630)
    ├── favicon-32.png         ← иконка вкладки
    ├── favicon-192.png
    ├── apple-touch-icon.png
    └── templates/             ← картинки шаблонов, по папке на шаблон
        └── imen/ cover.jpg, 01.jpg, 02.jpg …, bg.jpg
```

## Публикация

1. Создать репозиторий `givelove` и загрузить содержимое этой папки в корень.
2. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.
3. В `index.html` заменить `USERNAME` в `og:url` и `og:image` на свой логин GitHub.

Адрес сайта: `https://USERNAME.github.io/givelove/`

## Как добавить шаблон

Каждый шаблон — это одна запись в массиве `T` в файле `js/data.js` плюс папка с картинками.

**1. Картинки.** Создай папку `images/templates/<id>/` и положи туда страницы журнала, выгруженные из Canva в JPG
(Поделиться → Скачать → JPG, все страницы). Назови их по порядку: `01.jpg` (обложка), `02.jpg`, `03.jpg` …
Желательно ширина ~1000 px и сжатие, чтобы сайт грузился быстро.
По желанию — `bg.jpg`, фон блока в каталоге.

**2. Запись в `js/data.js`.** Скопируй образец и вставь внутрь `const T = [ … ]` (после любой `},`):

```js
 {id:'graduate',                 // латиницей, как папка с картинками
  name:'Выпускница',             // название на сайте
  cat:'family',                  // категория (см. ниже)
  catName:'Для семьи',           // подпись категории под названием
  price:695,                     // цена в рублях
  old:890,                       // старая цена (необязательно — для скидки)
  pages:24,                      // сколько страниц
  pop:5,                         // порядок «популярные»: больше — выше
  tag:'Новинка',                 // бейдж: 'Хит', 'Новинка' (необязательно)
  desc:'Журнал для выпускницы: школьные годы, друзья и пожелания учителей.',
  bgImg:'images/templates/graduate/bg.jpg',          // необязательно
  pageImgs:[
    'images/templates/graduate/01.jpg',
    'images/templates/graduate/02.jpg',
    'images/templates/graduate/03.jpg'
    // … и так до последней страницы
  ],
  buyUrl:'https://t.me/GiveLoveBot?start=graduate'  // куда ведёт «Купить» (появится с ботом)
 },
```

Обложкой станет первая картинка, листалка сама посчитает развороты по количеству картинок.

**3.** Сохрани, загрузи на GitHub — через минуту шаблон появится на сайте.

Поля `mast, font, bg, fg, acc, issue, head, subs, toc, q, layout` у нынешних шаблонов нужны только
для нарисованных демо-обложек. Когда шаблон получает картинки, они не нужны.

## Категории

Категории живут в двух местах файла `js/data.js`:

1. **Список кнопок-фильтров** — строка `const CATS = [...]`:
   ```js
   const CATS=[['all','Все'],['birthday','День рождения'],['couple','Для пары'],['family','Для семьи'],['sets','Наборы −20%']];
   ```
   Каждая пара — `['код','Название на кнопке']`.
2. **Поле `cat` у шаблона** — тот же код. Шаблон с `cat:'couple'` покажется по кнопке «Для пары».

Новая категория, например «Для учителя»:
- в `CATS` добавить `['teacher','Для учителя']`;
- у шаблонов поставить `cat:'teacher', catName:'Для учителя'`.

Наборы лежат в массиве `SETS` и всегда попадают в категорию `sets`:
```js
 {id:'set-mama',name:'Мама + Именинница',items:['mama','imen'],price:1100,old:1390,pop:7},
```
`items` — id двух шаблонов из `T`.

## Оплата (план)

GitHub Pages — только витрина, сервера там нет. Оплату принимает Telegram-бот:

1. Покупатель жмёт «Купить» → открывается бот по ссылке `https://t.me/<бот>?start=<id шаблона>`.
2. Бот выставляет счёт через ЮKassa (подключается в @BotFather → Payments).
3. После оплаты бот сам присылает ссылку на шаблон в Canva.

На сайте для этого нужно только поле `buyUrl` у каждого шаблона — кнопка «Купить» уже умеет его открывать.
Сам бот — отдельная небольшая программа, ей нужен хостинг (VPS или облачная функция).
